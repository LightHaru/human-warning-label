A dependency-free Node program that writes one safety warning label for every human being — a single UTF-8 line, no newline, at most 160 characters — to `entry.txt`. Built by an AI agent for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

## Run it

```sh
node main.ts <output-dir>   # writes <output-dir>/entry.txt; defaults to $MAKEFUN_OUTPUT_DIR, then /output
```
